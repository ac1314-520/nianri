念日 · NianRi 1.1.0 安卓安装说明
====================================

安装包：NianRi-Android-1.1.0.apk
包名：com.nianri.app
最低系统：Android 8.0（API 26）
SHA-256：见 SHA256-1.1.0.txt

一、本次更新
- 图片改为打开系统照片选择器 / 相册，不再进入文件管理器
- 颜色增加到 12 种
- 首页改为更清爽的日期头、独立卡片与悬浮新建按钮
- 纪念日卡片支持左滑删除，并可在 5 秒内撤销
- 详情页和编辑页做了一轮排版精简

二、安装 / 覆盖升级
1. 把 APK 传到手机（数据线、网盘、聊天文件传输等均可）。
2. 用文件管理器点开 APK。
3. 如果系统提示“禁止安装未知应用”，进入提示中的设置项，允许当前文件管理器 / 浏览器安装应用。
4. 返回后继续安装。小米手机可能还会弹出“安全检测”，选择继续安装即可。
5. 如果手机里已有旧版念日，直接覆盖安装即可保留数据；不要先卸载。
   新版本必须使用同一把签名密钥，本包与 1.0.0 使用的是同一把密钥。

三、第一次打开
1. 应用完全离线，不会要求登录，也没有广告。
2. 点击首页右下角朱砂色圆形按钮，写下第一个日子。
3. 可以添加一张照片、名字、日期、颜色、故事和提醒。
4. 第一次保存带提醒的日子，系统会询问通知权限，请允许。
5. 在任意纪念日卡片上向左滑动可以删除；删除后 5 秒内可以点“撤销”。
6. 想修改提醒检查时间：设置 → 提醒 → 每日检查时间。

四、小米 / Redmi / POCO（HyperOS / MIUI）
为了提醒尽量准时，建议完成以下设置：
1. 设置 → 应用设置 → 应用管理 → 念日 → 通知管理：允许通知。
2. 设置 → 应用设置 → 应用管理 → 念日 → 自启动：允许。
3. 同一页面的“省电策略”：改为“无限制”。
4. 如果系统有“闹钟与提醒”或“精确闹钟”权限，请允许。
5. 最近任务里给念日加锁，避免一键清理。

提示：不同 HyperOS 版本的菜单名称略有差异。应用内「设置」页有对应的入口和说明。

五、提醒为什么需要这些权限
- 通知权限：没有通知权限，提醒无法显示。
- 精确提醒：Android 12+ 需要单独授权；不授权时应用会自动降级，提醒可能稍晚送达。
- 开机恢复：重启手机后，应用会自动重新排程。
- 后台/自启动：小米系统可能会清理后台应用，允许自启动并设为无限制更稳。

六、关于数据
- 所有照片和纪念日都保存在应用私有目录，不上传服务器。
- 选择照片时只会临时授予所选图片的读取权限，不会获得整个相册的长期访问权限。
- 没有账号、广告或统计 SDK。
- 卸载应用会删除所有本地数据；升级安装不会。
- 如果开启了手机系统的云备份，数据可能由系统备份功能保存；这由你的系统设置决定。

七、关于在线更新
- 应用内默认没有预置更新源。请把安装包和 update.json 放到你自己的 HTTPS 地址，再在“设置 → 在线更新 → 更新源”里填写 update.json 的地址。
- 更新包必须使用同一把签名密钥；应用会校验 SHA-256、包名、版本号和签名。
- 详见 README 的“在线更新”章节。
