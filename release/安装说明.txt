念日 · NianRi 2.0.1 安卓安装说明
====================================

安装包：NianRi-Android-2.0.1.apk
包名：com.nianri.app
最低系统：Android 8.0（API 26）
SHA-256：见 SHA256-2.0.1.txt

一、本次更新
- 横版照片在首页卡片、详情和编辑页改为完整显示，留白用同图柔化背景补齐
- 竖版照片仍保持原来的铺满效果，不会出现左右空带
- 日期选择器重做：年份固定在顶部大号显示，左右箭头直接切换
- 月份、日期同样可以前后调整，底部显示完整日期和星期
- 更新源改为 refs/heads 地址，避开 raw 缓存返回旧清单
- 新增「工作台」：天气、心情、每日打卡、日记、记账、生理期和愿望清单
- 所有工作台记录只保存在本机

二、安装 / 覆盖升级
1. 把 APK 传到手机（数据线、网盘、聊天文件传输等均可）。
2. 用文件管理器点开 APK。
3. 如果系统提示“禁止安装未知应用”，进入提示中的设置项，允许当前文件管理器 / 浏览器安装应用。
4. 返回后继续安装。小米手机可能还会弹出“安全检测”，选择继续安装即可。
5. 如果手机里已有旧版念日，直接覆盖安装即可保留数据；不要先卸载。
   新版本使用与 1.0.0 / 1.1.0 / 1.2.0 / 1.3.0 / 2.0.0 相同的签名密钥，可以直接覆盖。

三、第一次打开
1. 先点右下角朱砂色圆形按钮，写下第一个纪念日；可以添加照片、名字、日期、颜色、故事和提醒。
2. 第一次保存带提醒的日子，系统会询问通知权限，请允许。
3. 首页右上角的四格图标是「工作台」，里面是日常记录。
4. 编辑纪念日时，横版照片会以完整画面显示；两侧留白是同一张图的柔化背景。
5. 选择日期时，年份固定在最上方，左右箭头可以切换；月份、日期在下方。
6. 天气第一次使用：点工作台的「设置」，输入城市名；之后点天气卡刷新，点「换城市」修改。
7. 工作台里可以直接记录心情、勾选今日打卡；日记、记账、生理期、愿望在「记录」页签中。
8. 在任意纪念日卡片上向左滑动可以删除；删除后 5 秒内可以点“撤销”。
9. 想修改提醒检查时间：设置 → 提醒 → 每日检查时间。
10. 有问题或想法：设置 → 反馈与建议。反馈会打开 GitHub Issue；需要登录 GitHub 才能提交。
    不方便公开或没有 GitHub 账号时，也可以加作者微信 MiManchi13l4520 反馈（在设置里点击微信号可复制）。
    提交前请检查内容，不要附带照片、纪念日标题或其他私密信息。

四、小米 / Redmi / POCO（HyperOS / MIUI）
为了提醒尽量准时，建议完成以下设置：
1. 设置 → 应用设置 → 应用管理 → 念日 → 通知管理：允许通知。
2. 设置 → 应用设置 → 应用管理 → 念日 → 自启动：允许。
3. 同一页面的“省电策略”：改为“无限制”。
4. 如果系统有“闹钟与提醒”或“精确闹钟”权限，请允许。
5. 最近任务里给念日加锁，避免一键清理。

提示：不同 HyperOS 版本的菜单名称略有差异。应用内「设置」页有对应的入口和说明。

五、提醒为什么需要这些权限
- 通知权限：没有通知权限，提醒无法显示。
- 精确提醒：Android 12+ 需要单独授权；不授权时应用会自动降级，提醒可能稍晚送达。
- 开机恢复：重启手机后，应用会自动重新排程。
- 后台/自启动：小米系统可能会清理后台应用，允许自启动并设为无限制更稳。

六、天气、数据与隐私
- 所有照片、纪念日、日记、打卡、记账、生理期和愿望记录都保存在应用私有目录，不上传服务器。
- 天气只使用你手动输入的城市名，不申请定位权限；城市和天气缓存保存在本机。
- 天气数据来自 Open-Meteo 公开接口；只有打开工作台或手动刷新天气时才会联网。
- 选择照片时只会临时授予所选图片的读取权限，不会获得整个相册的长期访问权限。
- 应用本身没有账号、广告或统计 SDK；反馈入口只会在你点击后打开 GitHub。
- 卸载应用会删除所有本地数据；升级安装不会。
- 如果开启了手机系统的云备份，数据可能由系统备份功能保存；这由你的系统设置决定。

七、生理期提示
应用里的生理期内容是一般生活建议，不替代医生诊断，也不用于避孕。它参考 NHS 与 ACOG 的公开资料；如果疼痛影响日常生活、出血量突然很大、经期超过 7 天，或伴发热、晕厥，请及时就医。

八、关于在线更新
- 2.0.1 默认使用念日公开仓库的清单：
  https://raw.githubusercontent.com/ac1314-520/nianri/refs/heads/main/release/update.json
- 但应用不会自动联网；手动检查更新，或在设置里主动开启「自动检查」后，才会访问这个地址。
- 想换成自己的清单：设置 → 在线更新 → 更新源。留空可以关闭在线检查。
- 更新包必须使用同一把签名密钥；应用会校验 SHA-256、包名、版本号和签名。
- 详见 README 的“在线更新”章节。
